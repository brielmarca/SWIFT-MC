# Project: Minecraft Server Store

## Goal
Production website/store for a Minecraft server.

## Visual source
The Google Stitch export is the design reference.
Do not redesign unless explicitly requested.

Reference files:
- stitch_nexus_mc_premium_store/code.html
- stitch_nexus_mc_premium_store/DESIGN.md
- stitch_nexus_mc_premium_store/screen.png

## Brand
- Black/dark UI
- Purple neon accent
- Premium esports/gaming aesthetic
- Use provided purple logo
- Minecraft elements should feel modern, not childish
- Avoid excessive glow and visual clutter

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS

## Rules
- Keep components reusable and readable
- Responsive desktop/mobile
- Use local assets from public/
- No fake backend logic
- No secrets in frontend
- Do not modify original Stitch reference files
- Work incrementally
- Do not implement future phases unless requested

## Phases
1. Homepage fidelity
2. Store and rank pages
3. Authentication
4. Checkout
5. Database
6. Payments/webhooks
7. Minecraft server integration
